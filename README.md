# EXCEL-SALES-ANALYSIS-FOR-COFFE-SHOP
SALES ANALYSIS DASHBOARD USING POWERPIV
=Coffee Shop Sales Analysis | Excel Dashboard

📌 Project Overview

This project analyzes coffee shop sales data using Microsoft Excel to explore sales performance, order trends, and customer purchasing patterns.

An interactive dashboard was developed to summarize key performance indicators and visualize sales activity across different time periods, coffee products, payment methods, and shifts.

🎯 Project Objectives

* Monitor overall sales performance using key metrics.
* Analyze order trends by month.
* Identify ordering patterns across different coffee types.
* Understand the distribution of orders by payment method.
* Compare order activity across shifts.
* Enable users to explore sales data by day of the week.

🛠️ Tools & Techniques

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Interactive Slicers
* Data Analysis
* Dashboard Design & Visualization

📊 Dashboard Features

1. Key Performance Indicators (KPIs)

The dashboard displays three key metrics:

* Total Sales: Overall sales revenue.
* Total Orders: Total number of orders.
* Total Items: Total number of items recorded in the dataset.

2. Orders by Month

Visualizes monthly order activity to explore trends and changes in order volume over time.

3. Orders by Coffee Name

Compares order counts across different coffee types to understand product-level ordering patterns.

4. Orders by Payment Method

Shows how orders are distributed across available payment methods.

5. Orders by Shift

Analyzes order activity across different shifts to identify variations in ordering patterns throughout the day.

6. Interactive Weekday Slicer

Allows users to filter the dashboard by day of the week and explore order activity for selected days.

⚙️ Methodology

1. Reviewed the source sales dataset.
2. Created multiple Pivot Tables to summarize the data.
3. Developed Pivot Charts to visualize key sales metrics and ordering patterns.
4. Added an interactive weekday slicer to support dynamic filtering.
5. Organized the visualizations into a consolidated Excel dashboard.

💡 Business Value

This dashboard provides a clear overview of coffee shop sales and order activity. It helps users explore monthly trends, compare coffee products, examine payment methods, and understand differences in order volume across shifts and weekdays.

These insights can support sales monitoring, product analysis, and operational planning.
